# pokemon damage calculate

## 仕様メモ（2026/09/23 時点）

### 実数値

1. 実数値HP
    ```
    floor((種族値×2 + 31) × 50/100) + 50 + 10 + 能力ポイント
    ```

2. 実数値HP以外
    ```
    floor((floor((種族値×2 + 31) × 50/100) + 5 + 能力ポイント) × 性格補正)
    ```

3. ランク補正

    **上昇値**
        
    ```
    floor(実数値 × (2+ランク) / 2)
    ```

    |ランク|0|+1|+2|+3|+4|+5|+6|
    | - | - | - | - | - | - | - | - |
    |倍率|2/2|3/2|4/2|5/2|6/2|7/2|8/2|

    **下降値**

    ```
    floor(実数値 × 2 / (2-ランク))
    ```

    |ランク|-6|-5|-4|-3|-2|-1|
    | - | - | - | - | - | - | - |
    |倍率|2/8|2/7|2/6|2/5|2/4|2/3|

### ダメージ計算
- 基礎ダメージと各補正ダメージごとに切り捨てされる

1. 基礎ダメージ
    ```
    floor((floor(2×レベル/5 + 2) × 技の威力 × 物理・特殊 / 防御・特防 / 50) + 2)
    ```
    - チャンピオンズではレベル50固定なので、floor(2×レベル/5 + 2)の部分は22固定となる

2. 各補正ダメージ
    - 各補正ダメージは基礎ダメージの計算後、乗算される
    
        |No.|補正名|倍率|条件|
        |--:|:--|--:| - |
        |1|ダブル補正|*0.75|ダブルで範囲技の場合|
        |2|天候|*1.5 / *0.5|晴れ(炎↑水↓)、雨(水↑炎↓)|
        |3|急所|*1.5|確率は1/24、壁無視|
        |4|乱数|*((85~100) / 100)|85~100の乱数|
        |5|タイプ一致|*1.5|技のタイプ=ポケモンのタイプ|
        |6|タイプ相性|*1/4 ~ 4|防御側のタイプで判定|
        |7|やけど|*0.5|物理技、特性=根性以外|
        |8|壁|*0.5 / 2732/4096|防御側：1匹(0.5)、2匹以上(2732/4096)|
        |9|まもる|*0|現状のチャンピオンズ仕様（ダイマックス環境だと異なる）|
        |10|持ち物|*様々|持ち物による|

    - 各補正ダメージは*0になることはない（例外はある）

3. 例外
    - 天候による防御上昇

        |天候|上昇率|条件|
        |:--|--:|:--|
        |砂嵐|1.5|岩タイプ|
        |雪・あられ|1.5|氷タイプ|
    
    
    - 特殊な技
        |技|倍率・計算|
        |:--|:--|
        |HP依存技|floor(150 × 現在HP / 最大HP)※最低1|
        |連続技|固定2、固定3、2~5回の3パターン|
        |てだすけ|技の威力 * 1.5|
    
    - フィールド
        |フィールド|倍率・計算|
        |:--|:--|
        |エレキ|電気タイプ技威力 * 1.3|
        |グラス|草タイプの技威力 * 1.3 / じしん・じならし・マグニチュードの威力 * 0.5|
        |ミスト|ドラゴンタイプの技威力 * 0.5|
        |サイコ|エスパータイプの技威力 * 1.3倍|
